# 내 명함첩 — 설치 안내서

폰으로 명함을 찍어 등록하고, 폰·태블릿·PC 어디서나 같은 명함첩을 보는 앱입니다.

- **폰·태블릿**: 크롬에서 열고 「앱 설치」를 누르면 홈 화면에 앱으로 깔립니다. 「명함 추가 → 사진 촬영」을 누르면 카메라 앱이 바로 열립니다.
- **PC·노트북**: 같은 주소를 브라우저로 열어 씁니다. 엣지·크롬에서는 PC용 앱으로도 설치됩니다.
- **명함 저장**: 구글 계정으로 로그인하면 Firebase 클라우드에 저장되어 모든 기기에 자동으로 맞춰집니다. 인터넷이 끊겨도 기기에 저장해 두었다가 연결되면 올립니다.
- **글자 인식**: 무료 인식기(Tesseract)가 기기 안에서 사진을 읽습니다. 사진이 외부 서버로 가지 않고 비용도 없습니다. 대신 정확도가 완벽하지 않아서, 인식 결과를 확인하고 「저장」을 눌러 등록합니다.

처음 한 번만 아래 5단계를 따라 하면 됩니다. 모두 무료이고 30분 정도 걸립니다.

---

## 1단계. GitHub에 올려서 웹 주소 만들기

1. [github.com](https://github.com)에 로그인하고 오른쪽 위 **＋ → New repository**를 누릅니다.
2. Repository name에 `cardbook`을 적고, **Public**을 고른 뒤 **Create repository**를 누릅니다.
3. 새 저장소 화면에서 **uploading an existing file** 링크를 누르고, 받은 zip을 푼 폴더 안의 파일과 `icons` 폴더를 모두 끌어다 놓은 뒤 **Commit changes**를 누릅니다.
4. 저장소의 **Settings → Pages**에서 Source를 **Deploy from a branch**, Branch를 **main / (root)** 로 고르고 **Save**를 누릅니다.
5. 1~2분 뒤 같은 화면 위쪽에 주소가 나옵니다. 예: `https://내아이디.github.io/cardbook/`

> 이후에는 GitHub에서 파일을 고치면 1~2분 뒤 자동으로 앱에 반영됩니다.

> 저장소를 Public으로 만들어도 **명함 데이터는 공개되지 않습니다.** 공개되는 것은 앱 화면 코드뿐이고, 명함은 Firebase에 본인만 볼 수 있게 저장됩니다.

## 2단계. Firebase 프로젝트 만들고 설정값 넣기

1. [console.firebase.google.com](https://console.firebase.google.com)에 구글 계정으로 들어가 **프로젝트 추가**를 누릅니다. 이름은 `cardbook` 정도로 적고, Google 애널리틱스는 꺼도 됩니다.
2. 프로젝트 첫 화면에서 **웹 아이콘 `</>`** 을 누르고 앱 이름(예: 내 명함첩)을 적은 뒤 **앱 등록**을 누릅니다. (Firebase 호스팅 체크는 하지 않습니다.)
3. 화면에 나오는 `const firebaseConfig = { ... }` 안의 값 6개(apiKey, authDomain, projectId, storageBucket, messagingSenderId, appId)를 복사해 둡니다.
4. GitHub 저장소에서 `firebase-config.js` 파일을 열고 연필(✏️) 아이콘을 누릅니다. 따옴표 안에 값을 붙여 넣고 **Commit changes**를 누릅니다.

```js
window.FIREBASE_CONFIG = {
  apiKey: "AIza....",
  authDomain: "cardbook-xxxx.firebaseapp.com",
  projectId: "cardbook-xxxx",
  storageBucket: "cardbook-xxxx.appspot.com",
  messagingSenderId: "1234567890",
  appId: "1:1234567890:web:abcd..."
};
```

## 3단계. 구글 로그인 켜기

1. Firebase 왼쪽 메뉴 **빌드 → Authentication → 시작하기**를 누릅니다.
2. **Sign-in method** 탭에서 **Google**을 고르고 **사용 설정**을 켠 뒤, 지원 이메일을 고르고 **저장**합니다.
3. 같은 화면의 **Settings → 승인된 도메인**에서 **도메인 추가**를 누르고 `내아이디.github.io`를 넣습니다. (`https://`와 `/cardbook`은 빼고 적습니다.)

## 4단계. 명함 저장소(Firestore) 만들기

1. 왼쪽 메뉴 **빌드 → Firestore Database → 데이터베이스 만들기**를 누릅니다.
2. 위치는 **asia-northeast3 (서울)** 을 고르고, **프로덕션 모드**로 시작합니다.
3. 만들어지면 **규칙** 탭을 열고, 들어 있는 내용을 지운 뒤 이 폴더의 `firestore.rules` 내용을 붙여 넣고 **게시**를 누릅니다.

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{uid}/{document=**} {
      allow read, write: if request.auth != null && request.auth.uid == uid;
    }
  }
}
```

## 5단계. 폰과 PC에서 쓰기

**Z플립 등 안드로이드 폰**
1. **크롬**으로 1단계 주소를 엽니다.
2. **Google 계정으로 로그인**을 누릅니다.
3. 위쪽의 **앱 설치** 버튼을 누릅니다. 버튼이 안 보이면 크롬 메뉴(⋮) → **홈 화면에 추가 → 설치**를 누릅니다.
4. 이제 홈 화면의 **명함첩** 아이콘으로 엽니다.

**PC·노트북**
1. 같은 주소를 크롬이나 엣지로 열고 **같은 구글 계정**으로 로그인합니다.
2. 주소창 오른쪽의 설치 아이콘을 누르면 PC용 앱으로도 쓸 수 있습니다.

## 쓰는 법

- **명함 등록**: 「명함 추가」 → **사진 촬영**. 명함이 화면에 꽉 차게, 밝은 곳에서 반듯하게 찍으면 잘 읽힙니다. 인식 결과를 확인하고 틀린 곳을 고친 뒤 **저장**합니다. 저장하면 **다음 명함 촬영** 버튼이 나와 여러 장을 이어서 등록할 수 있습니다.
- **처음 인식**: 인식 데이터(약 10MB)를 한 번 받느라 30초쯤 걸립니다. 그다음부터는 빠르고, 인터넷 없이도 인식합니다. 와이파이에서 처음 한 번 해 두면 좋습니다.
- **같은 사람 확인**: 이미 등록된 명함과 휴대폰이나 이메일이 같으면 저장 전에 알려 줍니다.
- **명함 전달**: 명함을 열고 「이 명함 전달하기」 → **글로 공유** 또는 **명함 이미지로 공유**를 누르면 폰의 공유 메뉴가 열려 카카오톡·문자로 바로 보낼 수 있습니다.
- **엑셀**: 「엑셀 받기」로 전체 명함을 내려받고, 「가져오기」로 리멤버 엑셀이나 CSV를 불러옵니다.

## 기존 명함첩(Claude 안의 명함첩)에서 옮기기

1. 기존 명함첩에서 **엑셀 받기**를 눌러 파일을 받습니다.
2. 새 앱에서 **가져오기**로 그 파일을 고릅니다.
3. 이름·회사·연락처·태그·메모와 함께 **연락 기록, 다음 연락일**도 옮겨집니다. 명함 **사진은 엑셀에 들어가지 않아 옮겨지지 않습니다.**

## 알아 둘 점

- **무료 범위**: Firebase 무료 요금제(Spark)는 저장 1GB, 하루 읽기 5만 번·쓰기 2만 번까지입니다. 명함 사진은 장당 약 200KB로 줄여 저장하므로 수천 장까지 무료로 쓸 수 있습니다. 결제 정보를 등록하지 않으면 요금이 나가지 않습니다.
- **세로 명함**: 세로로 된 명함은 사진도 세로로 찍어야 잘 읽힙니다.
- **아이폰·아이패드**: 사파리에서 열고 공유 버튼 → **홈 화면에 추가**로 설치합니다. 로그인이 막히면 사파리 설정의 **팝업 차단**을 잠시 꺼 주세요.

## 파일 구성

| 파일 | 하는 일 |
|---|---|
| `index.html` | 앱 화면과 기능 전체 |
| `ocr.js` | 명함 사진 글자 인식, 이름·회사·전화 등 항목 나누기 |
| `firebase-config.js` | Firebase 프로젝트 연결 값 (2단계에서 채움) |
| `firestore.rules` | 본인만 자기 명함을 읽고 쓰게 하는 보안 규칙 (4단계) |
| `manifest.webmanifest`, `sw.js`, `icons/` | 홈 화면 설치와 오프라인 실행 |
